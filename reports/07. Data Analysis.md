# 07. Data Analysis

## Metadata

- Project Title: Warehouse Product Demand and Forecasting Analysis
- Selected Method: SQL
- Dataset Source: `analytics.agg_monthly_demand`, `analytics.agg_sku_monthly`, `analytics.dim_warehouse`
- Analysis Period: 2012–2016 (Training `2012–2015`, Backtest Holdout `2016`, Proyeksi Baseline `2017`)
- Execution Date: 2026-11-27
- Environment / Tool Versions: Windows 11, DuckDB 2.0.0, Python 3.x

## Tujuan Tahap

Menjawab seluruh pertanyaan bisnis secara kuantitatif menggunakan segmentasi **ABC-XYZ**, klasifikasi prediktabilitas **Syntetos–Boylan**, perbandingan performa gudang dan Pareto kategori, serta evaluasi *out-of-sample backtesting* 5 model peramalan untuk menghasilkan proyeksi baseline `2017`.

## Metode dan Prosedur

Mengeksekusi `script/06_analysis.sql` dan `script/07_views.sql` untuk:
1. Segmentasi Pareto ABC (`<=80%` `A`, `80–95%` `B`, `>95%` `C`) dan volatilitas XYZ (`CV <= 0.5` `X`, `0.5–1.0` `Y`, `>1.0` `Z`) pada grid penuh `2.160 SKU × 60 bulan`.
2. Klasifikasi pola permintaan **Syntetos–Boylan** menggunakan `ADI = 60 / positive_months` dan `CV²` pada bulan aktif (`ADI < 1.32`, `CV² < 0.49` sebagai ambang baku literatur).
3. *Backtest* 12 bulan `2016` (`48` titik Gudang × Bulan) tanpa *data leakage* (indeks musiman pelatihan dihitung murni dari `2012–2015`) membandingkan `Naive (t-1)`, `Seasonal Naive (t-12)`, `Moving Average 3M`, `Moving Average 6M`, dan `Seasonal-MA6 Hybrid` dengan metrik **WAPE**, **MAE**, **RMSE**, dan **Bias %**.
4. Proyeksi 12 bulan `2017` menggunakan level H2 `2016` dikalikan indeks musiman historis `2012–2016` per gudang, lengkap dengan rentang ketidakpastian berbasis WAPE backtest masing-masing gudang.

## Data / Variabel yang Digunakan

`analytics.agg_sku_forecast_profile`, `analytics.forecast_backtest_warehouse_2016`, `analytics.forecast_model_benchmark_2016`, `analytics.forecast_projection_2017`, serta views analitik pada `script/07_views.sql`.

### 7–8. Segmentasi ABC-XYZ & Pola Syntetos–Boylan (`2012–2016`)

**Ringkasan Kelas ABC:**
- **Class A:** `84` SKU (`3,89%` dari `2.160` SKU) menggerakkan `4.067.032.600` unit (**`79,81%`** total Net Demand `2012–2016`).

**Ringkasan Pola Permintaan Syntetos–Boylan:**
- **Smooth (`ADI < 1.32, CV² < 0.49`):** `639` SKU (`29,58%` SKU) menghasilkan `4.566.175.314` unit (**`89,60%`** total volume!). Khususnya segmen **A-X Smooth** (`57` SKU = `2,64%` SKU) menguasai **`63,41%`** (`3,23 miliar` unit) dengan rata-rata `CV = 0,30` dan `ADI = 1,00`.
- **Erratic (`ADI < 1.32, CV² >= 0.49`):** `880` SKU (`40,74%` SKU) → `456.218.810` unit (`8,95%`).
- **Lumpy (`ADI >= 1.32, CV² >= 0.49`):** `534` SKU (`24,72%` SKU) → `50.023.657` unit (`0,98%`).
- **Intermittent (`ADI >= 1.32, CV² < 0.49`):** `107` SKU (`4,95%` SKU) → `23.629.497` unit (`0,46%`).

**Top 3 SKU Penggerak Volume:**

### Proyeksi Baseline 2017
Dengan menggabungkan level basis H2 `2016` dan indeks musiman historis `2012–2016`, total proyeksi permintaan bersih `2017` sebesar **`1.000.086.480` unit** dengan rentang batas ketidakpastian berbasis WAPE per gudang **`888.954.514` s.d. `1.111.218.449` unit** (`Whse_J`: `700,49M`; `Whse_S`: `135,56M`; `Whse_C`: `134,18M`; `Whse_A`: `29,85M`).

### 10. Statistical Testing
Uji hipotesis parametrik formal (*t-test* / *ANOVA*) tidak diterapkan (*Tidak relevan* sebagai uji inferensial populasi) karena analisis mencakup sensus lengkap pencatatan operasional `2012–2016`, bukan sampel acak, dan metrik evaluasi deret waktu menggunakan akurasi *out-of-sample* (WAPE, MAE, RMSE, Bias).

### 12. Analytical Findings & 13. Analysis Limitations
- **Temuan Kunci:** Hampir `90%` (`89,60%`) volume permintaan berasal dari SKU berpola `Smooth` (`639` SKU) sehingga sangat layak dimodelkan dengan metode deret waktu statistik, sedangkan `1.414` SKU `Erratic`/`Lumpy` (`65,46%` dari jumlah SKU) hanya mewakili `9,93%` volume dan lebih tepat dikelola lewat *safety stock* / *order-up-to* berbasis kuantil daripada peramalan titik agresif.
- **Keterbatasan:** Proyeksi `2017` bersifat *baseline* deret waktu murni tanpa memasukkan perubahan kapasitas gudang atau kontrak pelanggan baru; kontraksi struktural `Whse_S` di `2016` dapat berlanjut atau berbalik tergantung keputusan bisnis yang berada di luar dataset.

## Interpretasi dan Implikasi

Penerapan *Moving Average 6M* atau *Seasonal-MA6 Hybrid* menurunkan kesalahan peramalan agregat jaringan sebesar `8,0` poin persentase dibanding *Seasonal Naive (t-12)* (`11,21%–11,29%` vs `19,29%`) dan memangkas bias berlebih dari `+11,17%` menjadi `~1,1%`.
