# 08. Data Visualization

## Metadata

- Project Title: Warehouse Product Demand and Forecasting Analysis
- Selected Method: SQL
- Dataset Source: `dataset/demand_analytics.duckdb` (`analytics.vw_*` & tabel agregasi `analytics.*`)
- Analysis Period: 2012–2016 (60 bulan penuh) & Proyeksi Baseline 2017
- Execution Date: 2026-11-27
- Environment / Tool Versions: Windows 11, Next.js 15.5.29, TypeScript 5.8.3, Tailwind CSS 4.3.5, DuckDB Node API 2.0.1-r.1, Playwright 1.65.1

## Tujuan Tahap

Merancang dan memvalidasi dashboard analitik interaktif bertema *dark mode* satu halaman yang menyajikan temuan permintaan multi-gudang, segmentasi SKU, akurasi *backtest*, dan proyeksi `2017` secara jernih bagi pengambil keputusan tanpa menampilkan detail *stack* teknologi pada antarmuka pengguna.

## Metode dan Prosedur

1. Membangun aplikasi SPA dashboard di `dashboard/sql/` yang membaca data langsung dari basis data analitik melalui kueri SQL terparameter pada sisi server (`dashboard/sql/src/lib/db.ts` dan `dashboard/sql/src/app/api/dashboard/route.ts`).
2. Menerapkan antarmuka satu halaman (`dashboard/sql/src/components/DashboardClient.tsx`) dengan navigasi sidebar antar-seksi dan filter interaktif (`Gudang` & `Tahun`) tanpa membuat tata letak terpisah atau mengubah komposisi asli saat diekspor.
3. Menjalankan build produksi (`npm run build`), menguji filter interaktif serta rekonsiliasi angka langsung terhadap hasil kueri, lalu mengekspor 3 gambar PNG dashboard asli beresolusi tinggi melalui Playwright Chromium (`full-page`, `16:9`, dan `16:10`) dengan struktur yang identik.
4. Melakukan pemeriksaan visual langsung atas seluruh file PNG untuk memastikan tidak ada *clipping*, tumpang tindih, label terpotong, maupun kebocoran label *stack* teknologi.

## Data / Variabel yang Digunakan

Seluruh visualisasi mengonsumsi view terrekonsiliasi (`vw_kpi_summary`, `vw_monthly_trend`, `vw_warehouse_performance`, `vw_category_pareto`, `vw_abc_xyz_matrix`, `vw_sku_forecast_leaderboard`, `vw_seasonality_heatmap`, `vw_data_quality_summary`, `forecast_model_benchmark_2016`, `forecast_projection_2017`).

### 8–11. Dashboard Structure, Interactivity & Design Standards
- **Tema Visual:** *Dark mode* profesional (`#070b12` kanvas, `#0e1522` kartu, batas `#1f2d47`, aksen biru langit `#38bdf8`, zamrud `#34d399`, kuning `#fbbf24`, merah muda `#fb7185`).
- **Kebijakan Bahasa & Bebas Label Teknologi:** Judul dashboard tepat `Warehouse Product Demand and Forecasting Analysis`; seluruh label, deskripsi, wawasan, dan rekomendasi berbahasa Indonesia (dengan istilah teknis baku seperti `KPI`, `WAPE`, `MAE`, `RMSE`, `Bias`, `Backtest`, `Forecast`, `SKU`, `Smooth`, `Erratic`, `Lumpy`, `Intermittent`). Pemeriksaan otomatis `innerText` maupun inspeksi visual mengonfirmasi `0` penyebutan stack teknologi di antarmuka maupun ekspor PNG.

## Interpretasi dan Implikasi

Ketiga ekspor (`full-page`, `16:9`, dan `16:10`) mempertahankan komposisi dan struktur asli dashboard SPA secara konsisten—di mana `full-page` merekam seluruh halaman dari atas hingga footer dengan sidebar membentang utuh, sementara `16:9` dan `16:10` merekam tampilan *viewport* desktop asli pada resolusi `3840 px`.

## Validasi / Reproducibility

- Build produksi (`npm run build`) selesai tanpa error tipe maupun kompilasi.
- Pengujian endpoint `/api/dashboard?warehouse=Whse_S&year=2016` mengonfirmasi hasil `netDemand = 143.190.834` cocok 100% dengan kueri SQL Tahap 7.
