# 03. Data Profiling & Quality Assessment

## Metadata

- Project Title: Warehouse Product Demand and Forecasting Analysis
- Selected Method: SQL
- Dataset Source: `dataset/Historical Product Demand.csv`
- Analysis Period: 2011–2017 (keseluruhan `1.048.575` baris mentah)
- Execution Date: 2026-11-27
- Environment / Tool Versions: Windows 11, DuckDB 2.0.0, Python 3.x

## Tujuan Tahap

Mengukur tingkat kualitas data secara kuantitatif pada seluruh dimensi (*completeness*, *consistency*, *validity*, *uniqueness*, dan *outliers/anomalies*) sebelum menerapkan aturan pembersihan.

## Metode dan Prosedur

Menjalankan `script/03_data_quality.sql` terhadap `raw.product_demand_raw` (`1.048.575` baris) menggunakan pola regex (`^\d+$` dan `^\(\d+\)$`), fungsi kuantil `PERCENTILE_CONT`, agregasi per gudang, dan pengelompokan kombinasi 5 kolom penuh.

## Data / Variabel yang Digunakan

Tabel mentah `raw.product_demand_raw` (`product_code`, `warehouse`, `product_category`, `order_date_raw`, `order_demand_raw`).

Distribusi `Order_Demand` sangat condong ke kanan (*heavily right-skewed*): rata-rata (`4.867,43`) lebih dari `16x` median (`300`), menandakan keberadaan pesanan volume sangat besar (hingga `4.000.000` unit per baris).

**Temuan Penting pada `Whse_A` Missing Date:** `11.239` baris tanpa tanggal di `Whse_A` menghasilkan `Gross Demand = 5.584.740` unit namun `Net Demand = 10.090` unit—artinya terdapat `5.574.650` unit retur/penyesuaian negatif (`70,7%` dari total `7.884.524` unit retur `Whse_A`) yang tercatat tanpa stempel tanggal.

### 4. Duplicate Assessment
- Kombinasi unik seluruh 5 kolom (`Product_Code`, `Warehouse`, `Product_Category`, `Date`, `Order_Demand` trimmed): `926.152`.
- Kelompok dengan frekuensi > 1: `84.521` kelompok, menghasilkan `122.423` baris berulang (`11,6752%` dari total baris).
- Sebaran baris berulang menurut gudang: `Whse_J` (`98.844`), `Whse_A` (`20.939`), `Whse_S` (`1.991`), `Whse_C` (`649`).
- Karena sumber tidak memiliki kolom `Order_ID`, baris berulang ini **tidak dapat dipastikan sebagai duplikat sistem**; dapat berupa beberapa pesanan terpisah dengan kuantitas identik pada hari yang sama.

### 5. Data Consistency Assessment
- `Product_Code` → `Product_Category`: `0` SKU memiliki lebih dari 1 kategori (`100%` konsisten).
- `Warehouse` dan `Product_Category`: Penamaan kode konsisten (`Whse_*`, `Category_*`, `Product_*`).
- `Order_Demand` trailing spaces: `1.038.106` baris memiliki spasi di akhir string; `10.469` baris menggunakan format akuntansi bertanda kurung `(N)`.

### 6. Data Validity Assessment
- Baris integer polos valid setelah `TRIM`: `1.038.106` (`99,0016%`).
- Baris bertanda kurung `(N)` valid: `10.469` (`0,9984%`, total `-20.735.500` unit).
- Baris gagal parsing (`unparseable`): `0` (`0,0000%`).
- Seluruh nilai `Date` non-null (`1.037.336` baris) terurai valid sebagai tanggal kalender `YYYY/M/D`.

### 7. Data Uniqueness Assessment
Tidak ada kunci primer alami (*natural primary key*) pada data mentah; `row_id` sintetis diperlukan sebagai identitas unik baris.

### 8. Outlier & Anomaly Assessment

| Jenis Anomali | Jumlah Baris | Persentase | Dampak Volume / Keterangan |
|---|---:|---:|---|
| Permintaan bertanda kurung (`< 0`) | `10.469` | `0,9984%` | `-20.735.500` unit (`Whse_J`: 9,34M; `Whse_A`: 7,88M; `Whse_S`: 1,90M; `Whse_C`: 1,61M) |
| Permintaan bernilai nol (`= 0`) | `28.681` | `2,7352%` | Terbanyak di `Whse_A` (`24.636` baris) dan `Whse_J` (`3.836` baris) |

| Tahun batas parsial (`2011` & `2017`) | `693` | `0,0661%` | `2011`: `640` baris (7 bln); `2017`: `53` baris (s.d. 9 Jan 2017) |
| Nilai ekstrem positif (`> P99 = 75.000`) | Pesanan grosir hingga `4.000.000` | `< 1%` | Merepresentasikan pesanan curah/bulk B2B yang sah, bukan error pencatatan |

### 9. Data Quality Metrics

| Dimensi Kualitas | Skor / Tingkat | Catatan |
|---|---|---|
| **Completeness** (keseluruhan sel) | `99,7856%` | Hanya `Date` yang kosong (`1,0718%` dari baris; 100% di `Whse_A`) |
| **Validity** (format tanggal & angka) | `100,0000%` | `0` nilai tidak dapat di-parse (untuk baris non-null) |
| **Consistency** (hirarki SKU–Kategori) | `100,0000%` | `0` konflik kategori per SKU |
| **Uniqueness** (kombinasi 5 kolom) | `88,3248%` | `11,6752%` baris berulang karena ketiadaan `Order_ID` |

### 10. Data Quality Findings
1. Kualitas skema sangat baik pada `Product_Code`, `Warehouse`, dan `Product_Category` (0 null, 0 konflik kategori).
2. Dua risiko utama terletak pada `Whse_A` (seluruh `11.239` `missing Date` serta konsentrasi retur `5,22%` dan baris nol `24.636`) dan periode parsial `2011`/`2017`.
3. Nilai ekstrem positif hingga `4.000.000` unit merupakan karakteristik bisnis pesanan massal (*bulk demand*) dan tidak boleh dihapus sebagai *error*.
